# Changelog

## 1.1.0 — Minecraft 26.2

### Modules

- Added a searchable module menu with Core, HUD, PvP, and QoL categories.
- Added 16 information HUDs and a layout editor for 22 panels.
- Added CPS, keystrokes, combo, hit distance, and attack cooldown displays.
- Added low fire, a stable hurt camera, compact held items, and crosshair options.
- Added death waypoints, drop protection, chat timestamps, and a reconnect countdown.
- Added visual sky and weather settings, plus controls for scoreboard, boss bars, titles, and toasts.

### Included from 1.0

- Zoom and toggle sprint.
- FPS, ping, server address, and armor HUDs.
- Waypoints, custom crosshair, 3D skin layers, and flat dropped items.
- Saturation display and shulker box previews.
- Optional performance settings preset.
- MaLiLib settings and Mod Menu integration.

### Compatibility

- Minecraft Java Edition 26.2.
- Fabric Loader 0.19.5 or newer and Java 25 or newer.
- Fabric API, MaLiLib, Mod Menu, and Text Placeholder API.
